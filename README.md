## 🌐 О проекте

`ETVP_ComplexLayer` — это фундаментальный строительный блок для архитектур ИИ нового поколения. В отличие от стандартных слоев (`Linear`, `Conv`), которые работают со статистическими корреляциями векторов, данный слой оперирует **комплексным фазовым полем**, соблюдая законы сохранения энергии и причинности.

Слой реализует дискретный аналог уравнения реакции-диффузии:
$$ \Psi(t + dt) = \hat{U} \cdot \Psi(t) $$
где $\hat{U}$ — жесткий нелинейный фильтр, включающий комплексное вращение, кардиоидную активацию и диффузию (Лапласиан).

### Ключевые особенности ⚡️

*   **Топологическая когерентность:** Слой физически не способен "выучить" сингулярность или противоречивое состояние благодаря Z-принципу (ограничению нормы весов $R_{max}$).
*   **Фазово-коррелированный шум:** Стохастическая составляющая учитывает локальную фазу поля ($\text{atan2}(Im, Re)$), предотвращая разрушение геометрических структур при обучении SDE.
*   **Масштабно-инвариантная диффузия:** Лапласиан автоматически нормализуется под размер входной сетки ($H \times W$), позволяя использовать одну модель для разных разрешений.
*   **Два режима вычислений:**
    *   `increment`: Для задач динамики и RL (сохраняет инерцию состояния).
    *   `generate`: Для синтеза данных без наследования шума предыдущего шага.

## 📊 Математика преимущества

Стандартные активации (ReLU, GELU) отсекают пространство состояний. Кардиоидная активация этого слоя работает иначе:

1.  **Вдоль вектора фазы:** Сигнал проходит полностью (масштаб $1.0$).
2.  **Ортогонально вектору фазы:** Сигнал жестко подавляется (масштаб $0.0$).

Это дает динамический диапазон фильтрации более **$10^8 : 1$**. Слой идеально разделяет полезный сигнал и ортогональный ему хаос, что критично для обработки зашумленных физических сигналов.
